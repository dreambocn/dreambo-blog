## 代码实现
### write_page 函数

函数作用是写内容到指定的文件中
先对传入的文件号进行检查，是否符合规则，然后同lseek定位到指定文件的文件内容的偏移量
然后使用write写入内容到文件中
```C++
void DiskManager::write_page(int fd, page_id_t page_no, const char *offset, int num_bytes) {
    // Todo:
    // 1.lseek()定位到文件头，通过(fd,page_no)可以定位指定页面及其在磁盘文件中的偏移量
    // 2.调用write()函数
    // 注意处理异常
    
    // 检查文件描述符是否有效
    int flags = fcntl(fd, F_GETFD);  //fd是否可用
    if (flags == -1) {
        throw UnixError();
    }

    if(lseek(fd, page_no * PAGE_SIZE, SEEK_SET) == -1) {  //定位读写指针
        throw UnixError();
    }

    if(write(fd, offset, num_bytes) != num_bytes) { //写文件
        throw UnixError();
    }

}
```

### read_page 函数

同write一样先检查传入的参数是否符合规定，不符合规定的会抛出异常然后退出
同样用lseek锁定文件内容在磁盘中的偏移量
最后使用read函数读取文件的内容
```C++
void DiskManager::read_page(int fd, page_id_t page_no, char *offset, int num_bytes) {
    // Todo:
    // 1.lseek()定位到文件头，通过(fd,page_no)可以定位指定页面及其在磁盘文件中的偏移量
    // 2.调用read()函数
    // 注意处理异常
    // 检查文件描述符是否有效
    int flags = fcntl(fd, F_GETFD);  //fd是否可用
    if (flags == -1) {
        throw UnixError();
    }

    if(lseek(fd, page_no * PAGE_SIZE, SEEK_SET) == -1) {  //定位读写指针
        throw UnixError();
    }
    if(read(fd, offset, num_bytes) == -1) { //读文件
        throw UnixError();
    }
}
```

### AllocatePage 函数

先对传入参数进行检查，通过哈希表检查是否存在此 fd 已经被打开
然后从哈希表中取出对应 fd 的 page 文件磁盘路径，返回 page 文件磁盘路径，
使用fetch_add( )实现自增。
```C++
page_id_t DiskManager::AllocatePage(int fd) {
    // Todo:
    // 简单的自增分配策略，指定文件的页面编号加1
    
    // 检查文件描述符是否有效
    if(fd2path_.count(fd) == 0) {
        throw FileNotOpenError(fd);
    }

    page_id_t pid_t = fd2pageno_[fd].fetch_add(1);
    return pid_t;
}
```

### is_file 函数

使用stat获取文件的信息来判断是否存在此文件
先使用用于获取文件或目录的元数据
然后判断文件是否存，如果文件存在，返回true，如果文件不存在，返回false
```C++
bool DiskManager::is_file(const std::string &path) {
    // Todo:
    // 用struct stat获取文件信息
    struct stat st;
    // 如果文件存在，返回true
    // 如果文件不存在，返回false
    return stat(path.c_str(), &st) == 0;
}
```

### create_file 函数

先使用之前写完的`is_file`函数检查是否是文件，避免重复创建
然后使用`open`函数打开传入参数的文件地址,创建文件然后赋予O_CREAT函数,经测试还需要添加O_RDWR 以读写模式打开文件, 0644 指定文件的默认权限
如果返回的fd为-1则代表没有创建成功,抛出异常
正常则关闭文件
```C++
void DiskManager::create_file(const std::string &path) {
    // Todo:
    // 调用open()函数，使用O_CREAT模式
    // 注意不能重复创建相同文件
    if(is_file(path)){
        throw FileExistsError(path);
    }
    int fd = open(path.c_str(), O_CREAT | O_RDWR, 0644);
    if (fd < 0) {
        throw UnixError();
    }
    close(fd);
}

```

### destroy_file 函数

 先使用`is_file`函数检查是否为文件
 然后查哈希表检查文件是否已经被正常关闭
 没有问题则使用unlink删除文件 
```C++
void DiskManager::destroy_file(const std::string &path) {
    // Todo:
    // 调用unlink()函数
    // 注意不能删除未关闭的文件
    if (!is_file(path)) {
        throw FileNotFoundError(path);
    }
    // 检查文件是否已关闭
    if(path2fd_.count(path)) {
        throw FileNotClosedError(path);
    }
    // 删除文件
    if (unlink(path.c_str()) != 0) {
        throw UnixError();
    }
}
```

### open_file 函数

先进行两步检查，查询是否是文件且是否已经被打开过了
之后使用open用O_RDWR读写模式打开文件同样返回的fd值为-1则代表没有正常打开抛出异常
正常打开文件后要更新两个哈希表，表示系统已经打开文件
返回fd
```C++
int DiskManager::open_file(const std::string &path) {
    // Todo:
    // 调用open()函数，使用O_RDWR模式
    // 注意不能重复打开相同文件，并且需要更新文件打开列表
    
    // 检查文件是否存在
    if (!is_file(path)) {
        throw FileNotFoundError(path);
    }

    // 检查文件是否已打开
    if (path2fd_.count(path)) {
        throw FileExistsError(path);
    }

    // 打开文件
    int fd = open(path.c_str(), O_RDWR);
    if (fd < 0) {
        throw UnixError();
    }
    // 更新文件打开列表
    path2fd_[path] = fd;
    fd2path_[fd] = path;
    return fd;
}
```

### close_file 函数

先通过按照传入的参数`fd`从`fd2path_`表中查询是否已存在该文件，没有就显示已关闭
存在就进行下一步，关闭文件然后从两个哈希表中删除相关内容
```C++
void DiskManager::close_file(int fd) {
    // Todo:
    // 调用close()函数
    // 注意不能关闭未打开的文件，并且需要更新文件打开列表
    if(fd2path_.count(fd) != 0){
        close(fd);
        const std::string path = fd2path_[fd];
        path2fd_.erase(path);
        fd2path_.erase(fd);
    }   
}
```
