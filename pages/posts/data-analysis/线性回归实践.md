## 梯度下降法在实现线性回归中的作用

**梯度下降**是一种用于优化函数的算法，通过迭代地调整参数来最小化目标函数。在**线性回归**中，梯度下降用于找到最佳的模型参数，使得预测值与实际值之间的误差最小。

## 代码实现

梯度下降法实现
```python
# 梯度下降法实现
def gradient_descent(X, y, lr=0.1, n_iters=100):
    m = len(y)  # 样本数量
    X_b = np.c_[np.ones((m, 1)), X]  # 在特征矩阵中添加偏置项 (列向量)
    theta = np.random.randn(2, 1)  # 初始化参数 (随机值)
    loss_history = []  # 用于存储每次迭代的损失值

    for i in range(n_iters):
        # 计算梯度
        gradients = 2 / m * X_b.T.dot(X_b.dot(theta) - y)
        # 更新参数
        theta -= lr * gradients
        # 计算当前损失值 (均方误差)
        loss = np.mean((X_b.dot(theta) - y) ** 2)
        # 记录损失值
        loss_history.append(loss)
    
    return theta, loss_history
```
