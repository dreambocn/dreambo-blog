## Kmeans算法分析

### 算法执行过程

KMeans 算法的执行过程大致可以分为以下几个步骤：
1. **初始化阶段**  
   根据指定的初始化模式（随机方式或 k-means||）进行初始化：  
   - 如果选择随机初始化（RANDOM），则随机采样 k 个数据点作为初始聚类中心。  
   - 如果使用 k-means|| 初始化（默认模式），则先随机选取一个初始中心，然后通过多次迭代，每次根据点到当前中心的距离平方概率选择更多候选中心，最后通过本地 k-means++ 算法从候选中心中选取最终的 k 个中心。
2. **迭代更新阶段
   进入迭代过程，直到达到最大迭代次数或所有中心的移动都小于预设阈值 epsilon。每次迭代包括以下操作：  
   - **广播当前中心**：把当前中心列表广播到各个分区。  
   - **统计数据**：判断是否需要在局部或分布式计算计算中心间的统计信息，用于加速距离计算。  
   - **计算点到中心的距离**：每个数据点计算与每个中心的距离，找到最近的中心，同时累加点对应的代价（距离平方累计），并把点的向量加到该中心的累加器中，累加器同时记录点的权重之和。  
   - **更新中心**：对每个中心，根据所有归属于它的点求加权均值，得到新的中心。如果某个中心的移动距离大于 epsilon，则认为还没收敛。  
3. **结束**  
   当迭代次数达到最大值或者所有中心都收敛时，算法终止，返回 KMeansModel。

### 样例数据执行过程

下面给出一个简单的样例，假设我们有 6 个二维数据点，并希望将它们聚成 2 类。假设使用随机初始化（RANDOM 模式），maxIterations = 10，epsilon 为一个比较小的值（比如 1e-4）。数据如下：

- 点 A: [1.0, 1.0]
- 点 B: [1.1, 1.0]
- 点 C: [0.9, 1.2]
- 点 D: [5.0, 5.0]
- 点 E: [5.1, 4.9]
- 点 F: [4.8, 5.2]

整个执行过程可以概括为下面几个步骤：

1. **初始化**  
   假设随机初始化随机抽取到了点 A 和点 E 作为初始中心，此时初始中心为：  
   - Center1 = [1.0, 1.0]  
   - Center2 = [5.1, 4.9]

2. **第一次迭代**  
   对于每个数据点，计算到两个中心的距离，找出最近的聚类中心，并累计加权和和权重（每个点默认权重为 1.0）。例如：  
   - 点 A 到 Center1 距离 0，到 Center2 距离 ≈ 5.69，归入 Center1  
   - 点 B ([1.1, 1.0]) 离 Center1 的距离约 0.1，归入 Center1  
   - 点 C ([0.9, 1.2]) 离 Center1 的距离约 0.22，归入 Center1  
   - 点 D ([5.0, 5.0]) 离 Center1 距离 ≈ 5.66，离 Center2 距离 ≈ 0.14，归入 Center2  
   - 点 E ([5.1, 4.9]) 显然归入 Center2  
   - 点 F ([4.8, 5.2]) 离 Center2 距离约 0.36，归入 Center2  

   接下来更新中心：  
   - 对 Center1：平均 [1.0, 1.0]、[1.1, 1.0]、[0.9, 1.2] 得到新 Center1 = ([1.0+1.1+0.9] / 3, [1.0+1.0+1.2] / 3) ≈ [1.0, 1.07]  
   - 对 Center2：平均 [5.0, 5.0]、[5.1, 4.9]、[4.8, 5.2] 得到新 Center2 = ([5.0+5.1+4.8] / 3, [5.0+4.9+5.2] / 3) ≈ [4.97, 5.03]

   同时计算代价（各点与所属中心之间平方距离累加）。

3. **后续迭代**  
   使用更新后新的中心继续迭代。在每一轮中：  
   - 广播新的中心  
   - 每个分区计算各点到两个中心的距离，选出最近中心，并累加对应的向量和和权重  
   - 对所有分区的结果进行 reduce 得出全局新的向量和  
   - 更新中心后判断两个新的中心与上一次的是否已经移动小于 epsilon。如果都满足阈值条件，则算法收敛，否则继续下一轮迭代。

4. **结束**  
   当迭代次数达到上限或中心收敛时（本例中预计经过几次迭代中心已经稳定），算法结束，返回 KMeansModel，其记录最终中心、总代价和迭代次数。

### 源码分析

1. **RDD 转换流程**  
   在 runAlgorithmWithWeight 方法中，从初始化完成后的 centers 开始，每一次迭代都需要：  
   - 将当前 centers 封装到广播变量（bcCenters）中，使每个分区都能访问相同的中心数据。  
   - 调用 data.mapPartitions 处理每个分区里的 VectorWithNorm 数据，利用 bcCenters 中的中心及其它统计信息（如广播的统计数据 bcStats）为每个数据点计算到各中心的距离。  
   - 在每个分区内，利用 mapPartitions 遍历所有数据点，根据距离找到最近的中心，并对该中心对应的点累加其向量（sums）与权重（clusterWeightSum）。  
   - 最后通过 Iterator.tabulate 构造一个迭代器，每个分区输出 (中心索引, (累加向量, 累加权重)) 的形式。
   ![image.png](https://s2.loli.net/2025/05/06/n9tdKgUz8wN3FkV.png)


2. **mapPartitions 与 map 操作**  
   ![image.png](https://s2.loli.net/2025/05/06/abJslvzLBWfRQgZ.png) 
   - `mapPartitions` 对每个分区的数据进行批量处理，减少了每个记录单独调用函数的开销。  
   - 内部使用 `points.foreach` 遍历每个点，使用 distanceMeasureInstance 的方法计算最近中心，并更新累加结果。  
   - 最后使用 `Iterator.tabulate`构造出每个分区对应多个中心的中间汇总结果。

3. **reduceByKey 汇总**  
   后续调用 reduceByKey 对所有分区的统计结果按中心索引进行合并：
   ![image.png](https://s2.loli.net/2025/05/06/zknYbClxwIsSJpM.png)
   - 通过 reduceByKey，将来自各分区相同中心索引 (j) 的 (sums, clusterWeightSum) 合并为全局的累加结果。  
   - 其中 axpy 用于执行向量加法操作，将第二个累加向量加到第一个中，以及对权重做简单加和。  
   - 最后 collectAsMap 将所有中心的合并结果收集到驱动节点，用于更新最终的中心向量。

4. **中心更新与收敛判断**  
   收集完累加结果后：  
   - 针对每个中心索引 j，利用累加结果计算新的质心，调用 distanceMeasureInstance.centroid，即对每个维度除以总权重得到加权均值。  
   - 然后调用 isCenterConverged 判断新旧中心是否移动小于 epsilon，决定当前迭代是否已经收敛。

## NaiveBayes算法分析
### 算法执行过程
Naive Bayes 算法的执行过程主要包括以下几个阶段：

1. **数据准备与转换**  
   - 在 run 方法中，将 RDD 转换为 DataFrame（通过 toDF），以适配 Spark ML 中的 NaiveBayes 算法。

2. **模型训练**   
   - 训练过程中，算法根据特征值统计每个类别出现的先验概率（pi）和各类别下各特征的条件概率（theta），并通过加入平滑项（lambda）来防止零概率问题。
   - 训练后的结果中，pi 和 theta 分别存储类别先验的对数值以及类别条件概率的对数矩阵。

3. **模型构建与封装**  
   - 将训练结果中的 pi 数组和 theta 矩阵封装到 NaiveBayesModel 中，同时记录类别标签和模型类型
   - 对于 Bernoulli 版本，额外预计算了 log(1 - exp(theta)) 以及补偿项，以便在后续预测时正确计算 0/1 二值特征的概率。

4. **预测过程**  
   - 对于批量预测，模型先将自身广播到各个分区，然后每个分区对输入样本执行预测。  
   - 计算时会将输入特征与 theta 矩阵做乘法，并加上先验向量 pi，得到各类别的对数概率。
   - 根据模型类型，使用相应的计算方式得到预测的对数概率，再经过 softmax 操作转换为后验概率或直接取 argmax 得到预测类别。
### 样例数据执行过程
### 1. 样例数据

点A：[(1,0),0]
点B：[(2,1),0]
点C：[(2,3),1]
点D：[(0,2),1]
### 2. 训练过程

#### a. 统计先验概率
- 类别0有2个样本，类别1有2个样本，总共4个样本。
- 先验概率：
  - P(0) = 2/4 = 0.5
  - P(1) = 2/4 = 0.5

#### b. 统计条件概率
对每个类别，统计每个特征的出现次数，并加1做平滑：
假设平滑参数λ=1
- 类别0下：
  - 特征1总和 = 1 + 2 = 3
  - 特征2总和 = 0 + 1 = 1
  - 总特征和 = 3 + 1 = 4
- 类别1下：
  - 特征1总和 = 2 + 0 = 2
  - 特征2总和 = 3 + 2 = 5
  - 总特征和 = 2 + 5 = 7

拉普拉斯平滑后：
- 类别0：pi
  - P(特征1|0) = (3+1)/(4+2) = 4/6 ≈ 0.6667
  - P(特征2|0) = (1+1)/(4+2) = 2/6 ≈ 0.3333
- 类别1：
  - P(特征1|1) = (2+1)/(7+2) = 3/9 ≈ 0.3333
  - P(特征2|1) = (5+1)/(7+2) = 6/9 ≈ 0.6667

### 3. 预测新样本

假设新样本 x = [1, 1]，即特征1=1，特征2=1。

计算每个类别的后验概率（取对数防止下溢）：

- 对类别0：
  - log(P(0)) + 1*log(P(特征1|0)) + 1*log(P(特征2|0))
  - = log(0.5) + log(0.6667) + log(0.3333)
  - ≈ -0.6931 + (-0.4055) + (-1.0986) = -2.1972

- 对类别1：
  - log(0.5) + log(0.3333) + log(0.6667)
  - ≈ -0.6931 + (-1.0986) + (-0.4055) = -2.1972

两类概率相等，模型会返回其中一个（如返回类别0）。

### 源码分析
**NaiveBayesModel**  
表示朴素贝叶斯模型，包含类别标签（labels）、类别先验概率对数（pi）、条件概率对数（theta）、模型类型（modelType）。支持多项式（multinomial）和伯努利（bernoulli）两种模型。
**NaiveBayes**  
训练器类，负责模型训练。支持设置平滑参数（lambda）和模型类型。核心训练逻辑委托给 Spark ML 的新版 NaiveBayes 实现。

运算流程
用户调用 `NaiveBayes.train(rdd)`，实际调用 `NaiveBayes.run(data)`。
数据会被 map 成 `(label, features.asML)`，再转为 DataFrame，适配 Spark ML 的 NaiveBayes。
训练时，ML NaiveBayes 统计每个类别的先验概率和每个特征在各类别下的条件概率（均为对数形式，带平滑）。
训练结果（pi, theta, labels）被封装为 `NaiveBayesModel` 返回。

预测过程
预测时，分别对每个类别计算 log(P(label)) + sum_i x_i * log(P(feature_i|label))，取最大值为预测类别。伯努利模型会对特征为 0/1 做特殊处理，确保概率计算正确。还支持输出每个类别的后验概率分布。
