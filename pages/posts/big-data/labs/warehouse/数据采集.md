## 业务数据采集模块
配置maxwell
编辑/etc/mysql/my.cnf文件
![image.png](https://picture.dreambo.cn/2026/10/17/23/SyhUsMmJc5qfuwV-673afa9f48965eb29c551519ee14fac5.png)
重启mysql是更改同步
查看配置项修改成功
![image.png](https://picture.dreambo.cn/2026/10/17/23/X7kiHsMvJUlz9Pr-efe13b440d2ffeab076aff1f421f6cd7.png)
然后执行以下命令
```sql
CREATE USER IF NOT EXISTS 'maxwell'@'%' IDENTIFIED BY 'maxwell';  # 创建用户
GRANT ALL ON maxwell.* TO 'maxwell'@'%';  # 分配一个账号可以操作该数据库 
GRANT SELECT, REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO maxwell@'%'; # 分配这个账号可以监控其他数据库的权限
flush privileges; # 刷新mysql 表权限
```
